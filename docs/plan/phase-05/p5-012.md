# p5-012 — Wire Navigation, Breadcrumbs, Smoke Test, Build Verification

**Status:** `planned`

Wire up active view state, breadcrumb navigation, add a smoke test, and verify the full build pipeline.

## Steps

### 1. Wire active view state in `App`

```tsx
const [activeView, setActiveView] = useState<string>('providers');
```

Pass to `AppSidebar` as `activeView` and `onNavigate={setActiveView}`.

### 2. Implement `PageRouter`

Create `src/app/page-router.tsx`:

```tsx
const pages: Record<string, ReactElement> = {
  'providers': <ProvidersPage />,
  'credential-types': <CredentialTypesPage />,
  'integration-types': <IntegrationTypesPage />,
  'integration-runtimes': <IntegrationRuntimesPage />,
  'orgs': <OrgsPage />,
  'provider-accounts': <ProviderAccountsPage />,
  'credentials': <CredentialsPage />,
  'integrations': <IntegrationsPage />,
};

export function PageRouter({ activeView }: { activeView: string }): ReactElement {
  return pages[activeView] ?? <p>Page not found</p>;
}
```

### 3. Wire dynamic breadcrumbs

Define a lookup map from view key → `{ section, label }`:

```ts
const breadcrumbMap: Record<string, { section: string; label: string }> = {
  'providers': { section: 'Dictionaries', label: 'Providers' },
  'credential-types': { section: 'Dictionaries', label: 'Credential Types' },
  // ...
};
```

Render in the `SidebarInset` header:
```tsx
<BreadcrumbItem><BreadcrumbLink href="#">{section}</BreadcrumbLink></BreadcrumbItem>
<BreadcrumbSeparator />
<BreadcrumbItem><BreadcrumbPage>{label}</BreadcrumbPage></BreadcrumbItem>
```

### 4. Add smoke test

`src/app/app.spec.tsx`:
```tsx
import { render } from '@testing-library/react';
import App from './app';

it('renders without errors', () => {
  expect(() => render(<App />)).not.toThrow();
});
```

### 5. Verify

```bash
pnpm nx test inthub-inventory          # smoke test passes
pnpm nx typecheck inthub-inventory     # no type errors
pnpm nx build web                      # shell + all sub-apps build clean
```

Manual verification:
- `pnpm nx dev inthub-inventory` → `http://localhost:4204`
- Each nav item renders correct page with data
- Breadcrumb updates on navigation
- Sidebar collapses to icon mode
- Shell `http://localhost:3000` → IntHub Inventory in app-switcher under "IntHub"

## Definition of Done

- All 8 pages navigable from sidebar
- Breadcrumb reflects current section and page
- `pnpm nx test inthub-inventory` passes
- `pnpm nx build web` exits 0
- App appears in shell app-switcher and loads in iframe
