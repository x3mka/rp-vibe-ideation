# p5-007 — Integration Runtimes Page

**Status:** `planned`

Build the Integration Runtimes page: a read-only table listing all integration runtimes with type and status badges.

## Data Source

```ts
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const runtimes = database.integrationRuntimes;
```

No joins needed — all data is on the entity.

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `runtime.name` | |
| Type | `runtime.type` | `<Badge variant="outline">` — label only (Astronomer, N8N, EKS, Other) |
| Status | `runtime.status` | `<Badge>` with status variant |
| URL | `runtime.url` | Show as plain text or `—` if absent |

## Status Badge Variants

| Status | Variant |
|---|---|
| Active | `default` |
| Maintenance | `secondary` |
| Offline | `destructive` |
