# p5-011 — Integrations Page

**Status:** `planned`

Build the Integrations page: a read-only table listing all integration instances with org, integration type, source/target accounts, and status badge.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const integrations = api.getIntegrations();
```

Joins:
- Org: `api.getOrg(intg.orgId)?.name`
- Integration type: `api.getIntegrationType(intg.integrationTypeId)?.name`
- Source account: `api.getProviderAccount(intg.sourceAccountId)?.name`
- Target account: `api.getProviderAccount(intg.targetAccountId)?.name`

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `intg.name` | |
| Org | joined org name | |
| Integration Type | joined integration type name | |
| Source → Target | `sourceName → targetName` | Single cell, e.g. "Acme AWS Prod → Acme Splunk" |
| Status | `intg.status` | `<Badge>` with status variant |
| Last Run | `intg.lastRunAt` | Format as locale date string; show `—` if absent |

## Status Badge Variants

| Status | Variant |
|---|---|
| Active | `default` |
| Paused | `secondary` |
| Failed | `destructive` |
| Decommissioned | `outline` |

## Component

```
src/app/pages/integrations-page.tsx
```

Exported as `IntegrationsPage`. No props needed.

## Definition of Done

- Page renders a table with all integrations across all orgs
- All joins resolved correctly
- Source → Target displayed as a clear arrow string
- Status badge color-coded
- Last run date formatted or `—`
- `pnpm nx typecheck inthub-inventory` passes
