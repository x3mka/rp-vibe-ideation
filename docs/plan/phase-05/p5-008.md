# p5-008 — Orgs Page

**Status:** `done`

Build the Orgs page: a read-only table listing all organizations with status badge and provider account count.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const orgs = api.getOrgs();
```

Provider account count per org: `api.getProviderAccounts({ orgId: org.id }).length`

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `org.name` | |
| Status | `org.status` | `<Badge>` with status variant |
| Created At | `org.createdAt` | Format as locale date string |
| Provider Accounts | count | Number of ProviderAccounts belonging to this org |

## Status Badge Variants

| Status | Variant |
|---|---|
| Active | `default` |
| Offboarding | `secondary` |
| Suspended | `destructive` |

## Component

```
src/app/pages/orgs-page.tsx
```

Exported as `OrgsPage`. No props needed.

## Definition of Done

- Page renders a table with all orgs
- Status badge color-coded
- Provider account count computed correctly
- Dates formatted readably
- `pnpm nx typecheck inthub-inventory` passes
