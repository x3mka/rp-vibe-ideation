# p5-004 — Providers Page

**Status:** `planned`

Build the Providers page: a read-only table listing all providers from the IntHub data with a category badge.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const providers = api.getProviders();
```

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `provider.name` | |
| Category | `provider.category` | Rendered as `<Badge>` (label only, no status color) |
| Description | `provider.description` | May be undefined — show `—` if absent |

## Component

```
src/app/pages/providers-page.tsx
```

Exported as `ProvidersPage`. No props needed (reads directly from database at module level).

## Definition of Done

- Page renders a table with all providers from `inthub-data-inventory`
- Category displayed as a badge (outline variant, label-only)
- Missing description shows `—`
- `pnpm nx typecheck inthub-inventory` passes
