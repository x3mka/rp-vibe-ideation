# p5-001 — Scaffold `ideations/inthub-inventory`

**Status:** `planned`

Scaffold the `inthub-inventory` React+Vite sub-app, configure its base path and dev port, add the Nx copy target, wire it into the shell's build, and register it in the ideation-registry.

## Steps

### 1. Generate the app

```bash
pnpm nx g @nx/react:app inthub-inventory \
  --directory=ideations/inthub-inventory \
  --bundler=vite --style=css --routing=false --e2eTestRunner=none
```

### 2. Configure `vite.config.mts`

Set base path and ports (mirror `dashboard-app-1` but with inthub-inventory values):

```ts
export default defineConfig({
  base: '/apps/inthub-inventory/',
  server: { port: 4204, host: 'localhost' },
  preview: { port: 4204 },
  // ... rest of config
});
```

### 3. Add copy target to `ideations/inthub-inventory/project.json`

```json
{
  "targets": {
    "copy": {
      "dependsOn": ["build"],
      "command": "node -e \"require('fs').cpSync('ideations/inthub-inventory/dist','apps/web/public/apps/inthub-inventory',{recursive:true,force:true})\"",
      "options": { "cwd": "{workspaceRoot}" }
    }
  }
}
```

### 4. Add to shell's build `dependsOn` in `apps/web/project.json`

Add `"inthub-inventory:copy"` alongside the existing `"dashboard-app-1:copy"` entry.

### 5. Register in ideation-registry

Add to `packages/ideation-registry/src/lib/ideation-registry.ts`:

```ts
{
  id: 'inthub-inventory',
  name: 'IntHub Inventory',
  description: 'Read-only inventory view of the IntHub data model',
  group: 'IntHub',
  url: '/apps/inthub-inventory',
  devUrl: 'http://localhost:4204',
}
```

## Definition of Done

- `ideations/inthub-inventory/` exists as a valid Nx project
- `pnpm nx dev inthub-inventory` starts on port 4204
- `pnpm nx build inthub-inventory` produces output in `ideations/inthub-inventory/dist/`
- `pnpm nx copy inthub-inventory` copies assets to `apps/web/public/apps/inthub-inventory/`
- Registry entry is present and typechecks: `pnpm nx typecheck ideation-registry`
