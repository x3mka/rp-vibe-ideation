# p5-003 — AppSidebar

**Status:** `planned`

Build the `AppSidebar` component with an IntHub branding header, flat Main and Dictionaries nav sections, and a NavUser footer. Mirror the structure from `dashboard-app-1/src/app/components/app-sidebar.tsx`.

## Nav Structure

**Header**: Static IntHub branding (no dropdown). `Network` Lucide icon + "IntHub" title.

**Main section** (`SidebarGroupLabel: "Main"`):
| Title | Icon | View key |
|---|---|---|
| Orgs | `Building2` | `orgs` |
| Provider Accounts | `Server` | `provider-accounts` |
| Credentials | `KeyRound` | `credentials` |
| Integrations | `ArrowLeftRight` | `integrations` |

**Dictionaries section** (`SidebarGroupLabel: "Dictionaries"`):
| Title | Icon | View key |
|---|---|---|
| Providers | `Package` | `providers` |
| Credential Types | `Lock` | `credential-types` |
| Integration Types | `Workflow` | `integration-types` |
| Integration Runtimes | `Cpu` | `integration-runtimes` |

**Footer**: `NavUser` — static mock user (name, email, avatar).

## Component Structure

```
src/app/components/
└── app-sidebar.tsx
    ├── IntHubHeader()       — branding (no dropdown, no state)
    ├── NavSection()         — generic flat nav group (used for both sections)
    └── NavUser()            — copy from dashboard-app-1, same implementation
```

### `NavSection` props
```ts
interface NavSectionProps {
  label: string;
  items: { title: string; icon: LucideIcon; view: string }[];
  activeView: string;
  onNavigate: (view: string) => void;
}
```

Each item renders a `SidebarMenuButton` with `isActive={activeView === item.view}` and calls `onNavigate(item.view)` on click.

### `AppSidebar` props
```ts
interface AppSidebarProps extends React.ComponentProps<typeof Sidebar> {
  activeView: string;
  onNavigate: (view: string) => void;
}
```
