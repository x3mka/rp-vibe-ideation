# p5-002 — Layout Foundation

**Status:** `planned`

Set up the shadcn/ui component library, Tailwind CSS, path aliases, and a bare `App` skeleton that renders the SidebarProvider layout. Also add dependencies on `inthub-api` and `inthub-data-inventory`.

## Steps

### 1. Copy shadcn/ui components from `dashboard-app-1`

Copy these 11 files verbatim from `ideations/dashboard-app-1/src/components/ui/` to `ideations/inthub-inventory/src/components/ui/`:

- `avatar.tsx`
- `breadcrumb.tsx`
- `button.tsx`
- `collapsible.tsx`
- `dropdown-menu.tsx`
- `input.tsx`
- `separator.tsx`
- `sheet.tsx`
- `sidebar.tsx`
- `skeleton.tsx`
- `tooltip.tsx`

### 2. Add Table and Badge components

These are not in dashboard-app-1 — add them as new shadcn components:

- `src/components/ui/table.tsx` — standard shadcn Table (Table, TableHeader, TableBody, TableRow, TableHead, TableCell, TableCaption)
- `src/components/ui/badge.tsx` — standard shadcn Badge with variants: default, secondary, destructive, outline

### 3. Copy hooks and utils

- `ideations/dashboard-app-1/src/hooks/use-mobile.ts` → `src/hooks/use-mobile.ts`
- `ideations/dashboard-app-1/src/lib/utils.ts` → `src/lib/utils.ts`

### 4. Mirror Tailwind CSS setup

Copy `styles.css` from `dashboard-app-1` (Tailwind CSS v4 imports + CSS custom properties for sidebar, background, etc.).

### 5. Configure path alias `@/`

In `tsconfig.app.json`, ensure:
```json
{
  "compilerOptions": {
    "paths": { "@/*": ["src/*"] }
  }
}
```

In `vite.config.mts`, add:
```ts
resolve: {
  alias: { '@': path.resolve(__dirname, 'src') }
}
```

### 6. Add package dependencies

In `ideations/inthub-inventory/package.json`, add:
```json
{
  "dependencies": {
    "@rp-vibe-ideation/inthub-api": "*",
    "@rp-vibe-ideation/inthub-data-inventory": "*"
  }
}
```

Then run `pnpm install` to link workspace packages.

### 7. Create bare `App` skeleton

`src/app/app.tsx` — renders the full layout shell with placeholder content:

```tsx
export function App(): ReactElement {
  return (
    <SidebarProvider>
      <AppSidebar activeView="providers" onNavigate={() => void 0} />
      <SidebarInset>
        <header>...</header>
        <div className="flex flex-1 flex-col gap-4 p-4 pt-0">
          <p className="text-muted-foreground">Select a section from the sidebar.</p>
        </div>
      </SidebarInset>
    </SidebarProvider>
  );
}
```

## Definition of Done

- `pnpm nx typecheck inthub-inventory` passes (all imports resolve)
- `pnpm nx dev inthub-inventory` renders a page without console errors
- `@/components/ui/table` and `@/components/ui/badge` are importable
