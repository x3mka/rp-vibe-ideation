# p5-009 — Provider Accounts Page

**Status:** `done`

Build the Provider Accounts page: a read-only table listing all provider accounts globally with org name, provider name, status badge, and region.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const providerAccounts = api.getProviderAccounts();
```

Joins:
- Org name: `api.getOrg(pa.orgId)?.name`
- Provider name: `api.getProvider(pa.providerId)?.name`

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `pa.name` | |
| Org | joined org name | |
| Provider | joined provider name | |
| External ID | `pa.externalId` | |
| Status | `pa.status` | `<Badge>` with status variant |
| Region | `pa.region` | Show `—` if absent |

## Status Badge Variants

| Status | Variant |
|---|---|
| Active | `default` |
| Inactive | `secondary` |
| Suspended | `destructive` |

src/app/pages/provider-accounts-page.tsx
