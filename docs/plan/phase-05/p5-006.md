# p5-006 — Integration Types Page

**Status:** `done`

Build the Integration Types page: a read-only table listing all integration type templates with source provider, target provider, runtime, version, and status.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const integrationTypes = api.getIntegrationTypes();
```

Joins:
- Source provider: `api.getProvider(it.sourceProviderId)?.name`
- Target provider: `api.getProvider(it.targetProviderId)?.name`
- Runtime: `database.integrationRuntimes.find(r => r.id === it.runtimeId)?.name`

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `it.name` | |
| Source → Target | `sourceName → targetName` | Rendered as single cell, e.g. "AWS → Splunk" |
| Runtime | joined runtime name | |
| Version | `it.version` | |
| Status | `it.status` | `<Badge>` with status variant |
