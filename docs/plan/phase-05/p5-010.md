# p5-010 — Credentials Page

**Status:** `planned`

Build the Credentials page: a read-only table listing all credentials with provider account, org, credential type, status badge, and expiry date.

## Data Source

```ts
import { makeApi } from '@rp-vibe-ideation/inthub-api';
import { database } from '@rp-vibe-ideation/inthub-data-inventory';

const api = makeApi(database);
const credentials = api.getCredentials();
```

Joins:
- Provider account: `api.getProviderAccount(cred.providerAccountId)` → `pa.name`
- Org: `api.getOrg(pa.orgId)?.name`
- Credential type: `database.credentialTypes.find(ct => ct.id === cred.credentialTypeId)?.name`

## Table Columns

| Column | Source | Notes |
|---|---|---|
| Name | `cred.name` | |
| Provider Account | joined provider account name | |
| Org | joined org name | |
| Credential Type | joined credential type name | |
| Status | `cred.status` | `<Badge>` with status variant |
| Expires At | `cred.expiresAt` | Format as locale date string; show `—` if absent |

## Status Badge Variants

| Status | Variant |
|---|---|
| Active | `default` |
| Expiring | `secondary` |
| Expired | `destructive` |
| Revoked | `outline` |

## Component

```
src/app/pages/credentials-page.tsx
```

Exported as `CredentialsPage`. No props needed.

## Definition of Done

- Page renders a table with all credentials across all provider accounts
- All joins resolved correctly
- Status badge color-coded (Expiring in yellow/secondary is important UX signal)
- Expiry date formatted readably or `—`
