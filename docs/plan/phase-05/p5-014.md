# p5-014 — Org Switcher + per-org filtering in Main section

**Status:** `done`

Remove the Orgs page from the sidebar nav and replace it with an org-switcher
control placed in `SidebarContent` above the Main section. When a specific org
is selected, the three Main pages (Provider Accounts, Credentials, Integrations)
filter their rows to that org. "All" shows unfiltered data.

---

## Changes

### 1. Remove Orgs page

- Delete `src/app/pages/orgs-page.tsx`
- Remove `'orgs'` entry from `navMain` in `app-sidebar.tsx`
- Remove `'orgs': <OrgsPage />` from `page-router.tsx`
- Remove `orgs` from `breadcrumbMap` in `app.tsx`
- Change initial `activeView` in `App` from `'providers'` to `'provider-accounts'`

### 2. Add `OrgSwitcher` component in `app-sidebar.tsx`

New component, placed in `SidebarContent` **above** the `NavSection label="Main"` group.
Mirrors the `NavUser` visual pattern: `SidebarMenu > SidebarMenuItem > DropdownMenu`.

```tsx
interface OrgSwitcherProps {
  orgs: { id: string; name: string }[];
  selectedOrgId: string | null;   // null = All
  onOrgChange: (orgId: string | null) => void;
}
```

**Trigger** (`SidebarMenuButton size="lg"`):

```
┌─────────────────────────────────────────┐
│ [Building2 icon]  Acme Corp         v  │
│                   All Orgs              │
└─────────────────────────────────────────┘
```

- Left icon: `Building2` in a rounded square (same style as `IntHubHeader`'s icon box)
- Primary line: selected org name, or `"All Orgs"` when `selectedOrgId` is null
- Secondary line: `"Filter by org"` always
- Right: `ChevronsUpDown`
- In collapsed (icon-only) mode: tooltip shows selected org name or "All Orgs"

**Dropdown** (`side="bottom"`, `align="start"`, `sideOffset={4}`):

```
┌──────────────────────┐
│ Organisation         │  ← DropdownMenuLabel
├──────────────────────┤
│ ✓ All Orgs           │  ← checkmark when selected
│   Acme Corp          │
│   Titan Security     │
│   Vertex Labs        │
└──────────────────────┘
```

Use `Check` (lucide) icon sized `size-4 mr-2` on the active item; invisible spacer
(`<span className="size-4 mr-2" />`) on inactive ones so names stay aligned.

**Wiring in `AppSidebar`:**

```tsx
interface AppSidebarProps extends React.ComponentProps<typeof Sidebar> {
  activeView: string;
  onNavigate: (view: string) => void;
  selectedOrgId: string | null;       // new
  onOrgChange: (orgId: string | null) => void;  // new

```

Add a `SidebarGroup` (no label) in `SidebarContent` before the Main group:

```tsx
<SidebarGroup>
  <SidebarMenu>
    <OrgSwitcher
      orgs={orgs}
      selectedOrgId={selectedOrgId}
```

Populate `orgs` from `database.orgs` (import `database` from
`@rp-vibe-ideation/inthub-data-inventory` directly in `app-sidebar.tsx` — no
API call needed, orgs are static).

### 4. Thread `selectedOrgId` through `PageRouter`

`PageRouter` accepts `selectedOrgId: string | null` and passes it to the three
Main pages. Dictionary pages are unaffected and receive no prop.

```tsx
export function PageRouter({
  activeView,
  selectedOrgId,
}: {
  activeView: string;
  selectedOrgId: string | null;
}): ReactElement {
  const pages: Record<string, ReactElement> = {
    'provider-accounts': <ProviderAccountsPage selectedOrgId={selectedOrgId} />,
    credentials: <CredentialsPage selectedOrgId={selectedOrgId} />,
    integrations: <IntegrationsPage selectedOrgId={selectedOrgId} />,
    // Dictionaries — no org filter
    providers: <ProvidersPage />,
    'credential-types': <CredentialTypesPage />,
    'integration-types': <IntegrationTypesPage />,
    'integration-runtimes': <IntegrationRuntimesPage />,
  };
  return pages[activeView] ?? <p className="text-muted-foreground">Page not found.</p>;
}
```

### 5. Filter logic in Main pages

**ProviderAccountsPage** — pass `selectedOrgId` to `api.getProviderAccounts()`:

```ts
const accounts = api.getProviderAccounts(
  selectedOrgId ? { orgId: selectedOrgId } : {}
);
```

**IntegrationsPage** — pass `selectedOrgId` to `api.getIntegrations()`:

```ts
const integrations = api.getIntegrations(
  selectedOrgId ? { orgId: selectedOrgId } : {}
);
```

**CredentialsPage** — `api.getCredentials()` has no orgId filter; filter manually:

```ts
const allCredentials = api.getCredentials();
const credentials = selectedOrgId
  ? allCredentials.filter((c) => {
      const account = api.getProviderAccount(c.providerAccountId);
      return account?.orgId === selectedOrgId;
    })
  : allCredentials;
```

Each page accepts `{ selectedOrgId: string | null }` as props.
